# 常见问题

## `node: command not found`

Node.js 没有安装，或者当前终端没有加载安装路径。重新打开终端后再运行 `node --version`。如果仍然失败，先解决 Node.js 安装问题，不要继续执行 `npm install`。

## `npm install` 很慢或失败

先确认网络可用，再重试一次。把完整输出交给 Codex。不要随意删除 `package-lock.json`，也不要混用多个包管理器生成新的锁文件。

## `EADDRINUSE: address already in use`

5173 端口已经被另一个开发服务器占用。可以关闭之前的 Vite 进程，或者让 Vite 使用另一个端口：

```bash
npm run dev -- --port 5174
```

## 页面没有显示头像

检查三个条件：

1. 头像在 `src/assets/` 目录中。
2. 文件名去掉扩展名后，和 `contributors.json` 里的名字完全一致。
3. 扩展名是 `.png`、`.jpg`、`.jpeg` 或 `.webp`。

文件名中的大小写、空格和连字符都要一致。

## Git 提示没有要提交的文件

运行：

```bash
git status
git diff
```

确认你确实修改了文件，并且当前分支是自己的 Lab0 分支。新文件需要先用 `git add` 放进暂存区。

## 出现 merge conflict

不要直接删除冲突内容。打开 Git 标记出的文件，理解双方改动后保留正确版本，删除 `<<<<<<<`、`=======`、`>>>>>>>` 标记，再运行检查命令。看不懂时，把冲突文件和 `git status` 的输出完整发给 Codex。

## 我不知道下一步做什么

把这三样东西发出来：当前目标、你执行的命令、终端完整输出。导师需要上下文才能给出可靠建议。
