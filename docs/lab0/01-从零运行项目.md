# 从零运行项目

## 1. 准备环境

WisePenCat 使用 Node.js 运行前端工具。建议使用 Node.js 22；最低版本为 Node.js 20.19。

安装完成后，在终端确认版本：

```bash
node --version
npm --version
```

如果 `node` 或 `npm` 找不到，说明 Node.js 没有安装好，或者终端还没有加载新的环境变量。

## 2. 克隆仓库

先在 GitHub 上 Fork WisePenCat，再克隆你自己的 Fork：

```bash
git clone <你的Fork地址>
cd WisePenCat
```

如果你使用 SSH，地址通常以 `git@github.com:` 开头；如果使用 HTTPS，地址通常以 `https://github.com/` 开头。两种方式都可以。

## 3. 安装依赖

```bash
npm install
```

这一步会根据 `package.json` 安装 React、Vite、TypeScript 和图标库，并生成或更新 `package-lock.json`。依赖目录 `node_modules` 不需要提交。

## 4. 启动开发服务器

```bash
npm run dev
```

终端会显示类似下面的地址：

```text
Local: http://localhost:5173/
```

在浏览器打开这个地址。修改 `src` 下的文件后，页面通常会自动刷新。

## 5. 关闭和重新启动

在运行开发服务器的终端按 `Ctrl + C` 可以停止服务。下次进入项目后再次运行 `npm run dev` 即可。

## 6. 提交前检查

```bash
npm run typecheck
npm run build
```

`typecheck` 检查 TypeScript 类型，`build` 检查项目能否生成生产版本。两条命令都通过后再提交，能减少 CI 或 Review 中的返工。
