# Lab0 学习资料

欢迎大家来到 WisePenCat！

这是一个起步项目。大家最终要一起做出一个可爱的可视化猫猫工作台：调试页里的 Agent 状态会被映射成猫猫的动作，猫猫会根据任务排队、工作、校验和完成来变化。

Lab0 的任务很小，在Lab0中，你要把自己的名字和头像加入到 contributor 列表中，这会带你走完一次真实的协作流程：

1. 把项目从零跑起来。
2. 在 contributor 列表中加入自己的名字和头像。
3. 了解 Git 的基本概念和常用命令。
4. 创建分支、提交改动、发起 Pull Request。
5. 学会使用 Codex，定位问题、解释报错和验证修改。

过程中遇到环境、命令、权限或理解上的阻碍都很正常。先读对应资料，再把完整的报错信息带来，我们一起拆解问题。祝各位好运！

- [Git 是什么](./02-Git基础.md)：工作区、提交、分支、远程仓库和同步。
- [提交一次 Pull Request](./03-提交PullRequest.md)：从 Fork 到 PR 的完整流程。
- [使用 Codex 学习和调试](./04-Codex调试.md)：如何提问、提供上下文和验证结果。
- [Lab0 操作清单](./05-Lab0操作清单.md)：只做 contributor 改动时的最短路径。
- [常见问题](./06-常见问题.md)：依赖、端口、头像和 Git 冲突的排查方式。

## Lab0 的完成标准

- 你可以在本地打开 WisePenCat 页面。
- `src/contributors.json` 中有你的用户名。
- `src/assets` 中有与用户名同名的头像文件，例如 `alice.png`。
- 页面能显示你的名字和头像。
- 你提交了一个只包含 Lab0 改动的 Pull Request。

> 如果git和pull request对你来说有些难，你也可以让codex帮你完成这些操作。

Lab0 不要求你修改 Agent 逻辑，也不要求你实现猫猫工作台。那是后续实验的主题。
