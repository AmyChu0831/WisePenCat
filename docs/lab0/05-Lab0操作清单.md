# Lab0 操作清单

这是完成 Lab0 的最短路径。

## 准备

- [ ] Fork WisePenCat。
- [ ] 克隆自己的 Fork。
- [ ] 确认 Node.js 和 npm 可用。
- [ ] 运行 `npm install`。
- [ ] 运行 `npm run dev`，浏览器能打开页面。

## 添加自己

- [ ] 在 `src/assets/` 放入头像，例如 `alice.png`。
- [ ] 打开 `src/contributors.json`。
- [ ] 在数组中新增 `"alice"`，不要删除已有名字。
- [ ] 刷新页面，确认名字和头像出现。

## 提交 PR

- [ ] 创建分支：`git switch -c lab0/alice`。
- [ ] 查看 `git diff` 和 `git status`。
- [ ] 运行 `npm run typecheck`。
- [ ] 运行 `npm run build`。
- [ ] 只暂存自己的 Lab0 文件。
- [ ] 提交并 push 分支。
- [ ] 向主仓库的 `main` 发起 Pull Request。

完成后，你已经走完了一次真实的软件协作流程。后续 Lab 会在这个基础上继续增加猫猫工作台能力。
